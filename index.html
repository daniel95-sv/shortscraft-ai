Despliegue Docker & Servidor MCP

Puedes usar ShortsCraft AI en cualquier navegador de forma gratuita con el Modo Navegador, o conectar con el contenedor oficial de bilalnaseer/free-video-maker para renderizar con Kokoro TTS + Whisper.cpp + Remotion + FFmpeg en tu CPU local o VPS:

1. Ejecutar el servidor con Docker (Puerto 3123):
docker run -it --rm --name short-video-maker -p 3123:3123 \ -e LOG_LEVEL=debug \ -e PEXELS_API_KEY=TU_PEXELS_API_KEY_AQUI \ bilalnaseer/free-video-maker:latest
2. Conectar como Servidor MCP (Claude Desktop / Cursor / n8n):

Expone Server-Sent Events en tu servidor (ej: https://tu-servidor.com/mcp/sse o http://localhost:3123/mcp/sse en local):

{ "mcpServers": { "free-video-maker": { "url": "https://tu-servidor.com/mcp/sse" } } }
3. Endpoints REST Soportados:
  • GET /health — Verifica disponibilidad del servidor.
  • POST /api/short-video — Genera video con { scenes, config }.
  • GET /api/short-video/:id/status — Consulta estado de renderizado.
  • GET /api/short-video/:id — Descarga el MP4 renderizado.
  • GET /api/short-videos — Lista todos los videos del servidor.
  • DELETE /api/short-video/:id — Elimina un video del servidor.
  • GET /api/voices y GET /api/music-tags — Sincroniza voces y música.
