           Despliegue Oficial Docker y Servidor MCP (bilalnaseer/free-video-maker)
        

        
      


      

        

          Puedes usar esta página web sin instalar nada gracias al Modo Navegador, o levantar el contenedor oficial de bilalnaseer/free-video-maker para renderizar con Kokoro.js TTS + Whisper.cpp + Remotion + FFmpeg en tu propio equipo o VPS gratuito:
        


        

          
1. Ejecutar con Docker en 1 comando (Puerto 3123):

          
docker run -it --rm --name short-video-maker -p 3123:3123 \
  -e LOG_LEVEL=debug \
  -e PEXELS_API_KEY=TU_PEXELS_API_KEY_GRATIS \
  bilalnaseer/free-video-maker:latest

        


        

          
2. Conectar como Servidor MCP (Claude Desktop / Cursor / n8n):

          
El servidor expone SSE en http://localhost:3123/mcp/sse y mensajes en /mcp/messages con las herramientas create-short-video y get-video-status:

          
{
  "mcpServers": {
    "free-video-maker": {
      "url": "http://localhost:3123/mcp/sse"
    }
  }
}

        


        

          
3. Todos los Endpoints REST Soportados por esta Web:

          
    
            
  • GET /health — Verifica el estado del servidor.
    • 
            
  • POST /api/short-video — Crea un nuevo video con { scenes, config }.
    • 
            
  • GET /api/short-video/:id/status — Consulta estado (processing, ready, failed).
    • 
            
  • GET /api/short-video/:id — Descarga el binario MP4 renderizado.
    • 
            
  • GET /api/short-videos — Lista todos los videos en cola o terminados.
    • 
            
  • DELETE /api/short-video/:id — Elimina un video del servidor.
    • 
            
  • GET /api/voices & GET /api/music-tags — Sincroniza voces Kokoro y géneros musicales.
